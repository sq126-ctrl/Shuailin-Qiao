## Publish with GitHub Pages
1. Create a new **public** GitHub repository (for example, `personal-portfolio`).
2. Upload `index.html`, `style.css`, and this `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the live website URL after deployment.
